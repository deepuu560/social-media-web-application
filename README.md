# Social Media Web Application

An X-inspired social media web application built with React, Firebase, and Tailwind CSS.

## 🚀 Features

- User registration and login
- User authentication
- Create posts
- Edit and delete posts
- Like posts
- Comment on posts
- Follow and unfollow users
- User profiles
- Edit profile
- Search functionality
- Notifications
- Bookmark posts
- Image uploading
- Responsive user interface

## 🛠️ Tech Stack

- React.js
- JavaScript
- Vite
- Firebase
- Cloud Firestore
- Firebase Authentication
- Tailwind CSS
