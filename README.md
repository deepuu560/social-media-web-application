# Social Media Web Application

An X-inspired social media web application built with React, Firebase, and Tailwind CSS. This project provides a modern platform where users can create and interact with posts, connect with other users, manage profiles, and receive notifications.

## 🚀 Live Demo

https://social-media-web-application-ten.vercel.app/

## ✨ Features

- 🔐 User Registration & Login
- 👤 Firebase Authentication
- 📝 Create Posts
- ✏️ Edit Posts
- 🗑️ Delete Posts
- ❤️ Like & Unlike Posts
- 💬 Comment on Posts
- 👥 Follow & Unfollow Users
- 🔎 Search Users
- 👤 User Profiles
- ✏️ Edit Profile
- 🔔 Notifications
- 🔖 Bookmark Posts
- 🖼️ Image Uploads
- 📰 Social Media Feed
- 📱 Responsive User Interface

## ⚙️ Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm
- Git

### Installation

1. Clone the repository:

```bash
git clone https://github.com/deepuu560/social-media-web-application.git
```

2. Navigate to the project directory:

```bash
cd social-media-web-application
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local URL provided by Vite in your browser.

## 🔥 Firebase

This project uses Firebase for:

- User authentication
- User data
- Posts
- Comments

- Follow relationships
- Notifications

When configuring your own Firebase project, make sure Authentication and Firestore security rules are properly configured.
